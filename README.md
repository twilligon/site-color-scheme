# Site Color Scheme

Chrome extension to toggle `prefers-color-scheme` on a per-site basis [with the Web Preferences API](https://drafts.csswg.org/mediaqueries-5/#prefers-color-scheme).

Click the extension icon on a site to toggle light/dark mode, and persist an override for that site.
Open Extension options to view and edit your overrides, or to add a wildcarded override (e.g. `*.substack.com`).

No Web Store, sorry. Clone/download, Extensions > Load Unpacked.
